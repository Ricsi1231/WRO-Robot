# WRO-Robot

This is the Traktoristak team repository for the WRO robot competition, where we developed an autonomous robot.

- Nagy Richard - Mechatronics Engineering student, Team Lead, hardware and software developer
- Predrag Prijovic - Mechatronics Engineering student, Mechanical Design

This repository groups the project into three submodules:

- `hardware`: https://github.com/Ricsi1231/WRO-Robot-Hardware
- `software`: https://github.com/Ricsi1231/WRO-Robot-Software
- `mechanical`: https://github.com/Ricsi1231/WRO-Robot-Mechanical

## Cloning

Clone this repository with its submodules:

```bash
git clone --recurse-submodules https://github.com/Ricsi1231/WRO-Robot.git
```

If the repository was already cloned, initialize and update the submodules:

```bash
git submodule update --init --recursive
```
